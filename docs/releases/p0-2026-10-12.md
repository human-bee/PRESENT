## Runtime and data contract

One Node 24 LTS process owns native tldraw rooms and private durable access,
assets, jobs and workspace files. `npm ci`, `npm run dev` and `npm run build &&
npm start` are the native commands. All direct dependencies use exact researched
pins; [dependency decisions](p0-dependency-decisions.md) explain migration seams.

Authenticated Codex supplies actual restricted code execution. Current
account-visible Sol 6.1 is the ordinary default, Luna 6 handles bounded work and
Astra 6 supports demanding work. Account discovery controls availability.
Responses planning is a separate explicitly configured paid transport. GPT Live
uses `gpt-live-1`, with actual received TTS tested separately from provider tool
completion. Typed Decisions uses the calibrated Jev release for closed-choice
semantic judgments; ambiguous/unavailable judgments abstain.

Saved execution state gains an optional exact model field. Existing data remains
readable, while unknown, retired or mismatched thread models are refused rather
than silently upgraded. Completed historical outputs without known model
identity retain unknown provenance. A real 5.4 native snapshot fixture is loaded,
mutated and reopened under the coherent tldraw 5.5 family. No data reset is
required. Ordinary native edits retain the documented 150 ms persistence debounce;
an applied room mutation is not an acknowledgement of physical disk durability.

Required local model/call environment names: `CODEX_CLI_PATH` (optional when on
PATH), `PRESENT_MODEL_TRANSPORT`, `OPENAI_API_KEY` for voice or Responses,
`LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` for the human call. Optional
services use `TYPESAFE_API_KEY`, `CEREBRAS_API_KEY`, `LINEAR_API_KEY` and
`YOUTUBE_API_KEY`. Hosted operation also requires signed access, canonical
origin, persistent directories and build-time `VITE_TLDRAW_LICENSE_KEY`; see
[cloud readiness](../cloud-readiness.md). Values are never included in evidence.
